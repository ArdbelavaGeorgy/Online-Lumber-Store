# Интернет-магазин пиломатериалов

Статический сайт интернет-магазина пиломатериалов, экспортированный из WordPress/WooCommerce.

## 📋 Описание проекта

Интернет-магазин для продажи пиломатериалов с каталогом товаров, корзиной, оформлением заказа и личным кабинетом пользователя.

## 🛠 Технологии

- **WordPress 6.6.2** - CMS
- **WooCommerce 7.8.1** - плагин для интернет-магазина
- **Flatsome 3.17.0** - тема WordPress
- **HTML/CSS/JavaScript** - фронтенд
- **jQuery 3.7.1** - JavaScript библиотека
- **Yoast SEO** - SEO оптимизация
- **Contact Form 7** - формы обратной связи
- **Woo Product Filter** - фильтры товаров
- **Yandex Metrika** - аналитика

## 🎯 Основной функционал

- ✅ Каталог товаров с категориями и фильтрами
- ✅ Расширенные фильтры товаров (по породе дерева, назначению, сорту)
- ✅ Карточки товаров с описанием и изображениями
- ✅ Корзина покупок
- ✅ Оформление заказа
- ✅ Личный кабинет пользователя
- ✅ Информационные страницы (доставка, оплата, о компании, сертификаты)
- ✅ Блог/статьи
- ✅ RSS ленты для новостей и товаров
- ✅ Адаптивный дизайн
- ✅ SEO оптимизация (robots.txt, мета-теги)
- ✅ Интеграция с Yandex Metrika

## 📁 Структура проекта

```
├── application/          # Разделы сайта (фасад дома, лаги, напольные покрытия и т.д.)
├── product/              # Страницы товаров (68+ товаров)
├── product-category/     # Категории товаров (брус, доска, вагонка и т.д.)
├── product-tag/          # Теги товаров (породы дерева: сосна, лиственница, кедр и т.д.)
├── purpose/              # Назначение товаров (для бани, для стройки и т.д.)
├── sort/                 # Сорта товаров (экстра, первый, прима и т.д.)
├── shop/                 # Магазин с каталогом
├── cart/                 # Корзина покупок
├── checkout/             # Оформление заказа
├── my-account/           # Личный кабинет пользователя
├── dostavka-i-oplata/    # Доставка и оплата
├── o-kompanii/           # О компании
├── sertifikaty/          # Сертификаты
├── stati/                # Статьи/блог
├── wp-content/           # Контент WordPress (темы, плагины, загрузки)
├── wp-json/              # REST API endpoints
├── robots.txt            # Файл для поисковых систем
└── index.html            # Главная страница
```

## 🚀 Запуск проекта

Это статический сайт, который можно открыть локально:

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Или используйте локальный сервер (например, Live Server в VS Code)

## 📝 Примечания

- Проект представляет собой статический экспорт WordPress сайта
- Все файлы готовы к просмотру и демонстрации
- Для полноценной работы интернет-магазина требуется серверная часть WordPress
